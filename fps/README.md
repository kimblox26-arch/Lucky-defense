# OverKill 1

거대한 감염 구역에서 **AI 동료와 함께** 밀려드는 감염체 웨이브를 막아내는 **3D 웨이브 생존 FPS**.
배틀그라운드식으로 맵에 흩어진 무기·보급을 주워 쓰고, 맵을 골라 투입합니다.
브라우저에서 바로 실행되며 빌드 스텝이 없습니다.

> 이 폴더는 저장소 루트의 `index.html`(2D 타워디펜스 "운빨 디펜스")과 무관한 별도 프로젝트입니다.

---

## 실행

ES 모듈을 쓰므로 `file://`로는 열리지 않습니다. 아무 정적 서버나 띄우면 됩니다.

```bash
# 저장소 루트에서
python3 -m http.server 8080
# → http://localhost:8080/fps/

# 또는
npx serve .
```

GitHub Pages에 그대로 올려도 동작합니다 (`/fps/` 경로).

- 조준 보정은 기본값 `자동`(터치에서만 동작)이며 설정에서 강제로 켜고 끌 수 있습니다.

## 게임 방식

- 메인 메뉴에서 **맵을 고르고** 작전을 시작합니다.
- 맵에는 무기·탄약·구급킷·방어구가 **지상에 떨어져** 있고, 발광 기둥으로 표시됩니다.
  가까이 가서 `[E] 획득`으로 주울 수 있습니다. 웨이브를 제압하면 일부가 재보급됩니다.
- 설정에서 **AI 동료**를 0~2명 붙일 수 있습니다. 동료는 편대로 따라오며 가까운 감염체를
  자동 사격합니다. 피해를 입으면 무력화되었다가 재정비 후 복귀합니다.
- 웨이브마다 예산에 따라 감염체 구성이 짜입니다. 웨이브가 오를수록 종류가 해금되고
  여러 게이트에서 동시에 들어옵니다. 5의 배수는 보스 웨이브입니다.
- 웨이브를 제압하면 **강화 카드 3장 중 1장**을 고릅니다.
- 점수는 연속 처치 배수(최대 ×5)와 헤드샷 보너스로 늘어납니다. 최고 기록은 브라우저에 저장됩니다.

### 맵

| 맵 | 규모 | 특징 |
|---|---|---|
| 격리 구역 | 표준 | 콤팩트한 폐쇄 안뜰. 근접전이 잦고 템포가 빠르다 |
| 폐공장 지대 | 대형 | 컨테이너·배관이 얽힌 넓은 전장 |
| 개활 야적장 | 초대형 | 탁 트인 부지. 엄폐물이 드물어 사거리 관리가 관건 |

시간대는 **대낮**이며, 웨이브가 진행될수록 하늘이 황혼(골든아워)으로 물듭니다. 맵마다 하늘·조명 색조가 다릅니다.

### 감염체

| 종류 | 특징 |
|---|---|
| 보행체 | 기본. 느리지만 수가 많다 |
| 질주체 | 빠르고 도약한다. 체력은 낮다 |
| 중장갑체 | 느리고 단단하다. 몸통 피해 35% 감소 — 머리를 노려야 한다 |
| 분사체 | 거리를 유지하며 산성 포물선 투사체를 쏜다 |
| 자폭체 | 접근해 자폭한다. 붉게 달아오르면 피해야 한다 |

### 설계 메모

에셋 파일이 하나도 없습니다. 텍스처는 타일 가능한 밸류 노이즈로,
무기·손·감염체·동료·아레나 지오메트리는 코드로, 소리는 WebAudio로 전부 생성합니다.

- **맵은 config로 구동됩니다.** `world/Maps.js`의 프리셋이 크기(`half`)·게이트·프롭 밀도·
  하늘/조명 팔레트를 정하고, `Arena`가 이를 받아 스케일에 맞춰 벽·프롭·배관·감시탑을 배치합니다.
  맵 전환 시 아레나·충돌·플로우필드·환경맵을 재구축합니다.
- **뷰모델에 양손이 붙습니다.** 무기 길이에 맞춰 그립을 잡고, 재장전 때 지지 손이
  탄창을 빼러 내려갔다 삽입하며 복귀합니다. 스코프 완전 조준 시에는 가려지지 않게 숨깁니다.
- **텍스처 맵은 색이 아니라 디테일만 담습니다.** 실제 알베도는 버텍스 컬러가 담당합니다.
- **`InstancedMesh.setColorAt`은 머티리얼에 `vertexColors: true`가 있어야 합니다.**
- **포스트 합성(그레인·비네트·대비)은 톤매핑 뒤, 블룸은 톤매핑 앞**에 둡니다.
- **경로 탐색은 플로우 필드**입니다. 셀마다 설 수 있는 바닥 높이를 구워 BFS로 통행을 판정합니다.
  거대 맵에서도 개체당 O(1)로 동작합니다.
- **드로우콜**은 아레나(병합) + 감염체(부위별 인스턴싱) + 보급/동료(개별 메시) + 이펙트 수준으로,
  전투 중 대략 90~100 콜 안팎입니다.

### 품질 티어

`설정 → 품질`에서 수동으로 고를 수 있고, `자동`이면 하드웨어를 감지한 뒤
평균 프레임타임이 26ms를 넘으면 한 단계씩 내립니다.

| | 그림자 | 렌더 배율 | 블룸 | SMAA | 파티클 |
|---|---|---|---|---|---|
| 높음 | 2048 | 1.0 | ○ | ○ | 100% |
| 보통 | 1024 | 0.85 | ○ | ✕ | 65% |
| 낮음 | 없음 | 0.68 | ✕ | ✕ | 35% |

## 개발용 디버그 훅

콘솔에서 `window.__debug`로 접근할 수 있습니다.

```js
__debug.start()          // 게임 시작 (현재 선택 맵)
__GAME.beginRun('yard')  // 특정 맵으로 시작 (quarantine / factory / yard)
__debug.stats()          // FPS / 드로우콜 / 삼각형 수
__debug.setWave(12)      // 특정 웨이브로 점프
__debug.spawn(2, 5)      // 중장갑체 5마리 소환 (타입 0~4)
__debug.unlockAll()      // 무기 전부 해금
__debug.god(true)        // 무적
```
