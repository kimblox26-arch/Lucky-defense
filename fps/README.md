# DEAD WAVE — 데드 웨이브

격리 구역 07에서 4개의 게이트로 밀려드는 감염체를 막아내는 **3D 웨이브 생존 FPS**.
브라우저에서 바로 실행되며 빌드 스텝이 없습니다.

> 이 폴더는 저장소 루트의 `index.html`(2D 타워디펜스 "운빨 디펜스")과 무관한 별도 프로젝트입니다.

---

## 실행

ES 모듈을 쓰므로 `file://`로는 열리지 않습니다. 아무 정적 서버나 띄우면 됩니다.

```bash
# 저장소 루트에서
python3 -m http.server 8080
# → http://localhost:8080/fps/

# 또는
npx serve .
```

GitHub Pages에 그대로 올려도 동작합니다 (`/fps/` 경로).

| 마우스 우 | 정밀 조준 |
| `R` | 재장전 |
| `1`~`5` / 휠 / `Q` | 무기 전환 |

| 모바일 | |
|---|---|
| 좌측 화면 | 가상 스틱 (끝까지 밀면 질주) |
| 우측 화면 | 드래그로 시야, 짧게 탭하면 사격 |

조준 보정은 기본값 `자동`(터치에서만 동작)이며 설정에서 강제로 켜고 끌 수 있습니다.

## 규칙

- 웨이브마다 예산에 따라 감염체 구성이 짜입니다. 웨이브가 오를수록 종류가 해금되고
  여러 게이트에서 동시에 들어옵니다. 5의 배수는 보스 웨이브입니다.
- 웨이브를 제압하면 **강화 카드 3장 중 1장**을 고릅니다. 무기 보급도 카드로 나옵니다.
- 점수는 연속 처치 배수(최대 ×5)와 헤드샷 보너스로 늘어납니다.
- 최고 점수와 최고 웨이브는 브라우저에 저장됩니다.

### 감염체

| 종류 | 특징 |
|---|---|
| 보행체 | 기본. 느리지만 수가 많다 |
| 질주체 | 빠르고 도약한다. 체력은 낮다 |
| 중장갑체 | 느리고 단단하다. 몸통 피해 35% 감소 — 머리를 노려야 한다 |
| 분사체 | 거리를 유지하며 산성 포물선 투사체를 쏜다 |
| 자폭체 | 접근해 자폭한다. 붉게 달아오르면 피해야 한다 |

### 설계 메모

에셋 파일이 하나도 없습니다. 텍스처는 타일 가능한 밸류 노이즈로,
무기·감염체·아레나 지오메트리는 코드로, 소리는 WebAudio로 전부 생성합니다.

- **텍스처 맵은 색이 아니라 디테일만 담습니다.** 실제 알베도는 버텍스 컬러가 담당합니다.
  둘 다 색을 가지면 곱해져서 표면이 새까매집니다.
- **`InstancedMesh.setColorAt`은 머티리얼에 `vertexColors: true`가 있어야 합니다.**
  three의 `color_fragment` 청크가 `USE_COLOR`로만 가드되어 있기 때문입니다.
  그리고 지오메트리에 흰색 `color` 속성이 없으면 `vColor`가 0이 됩니다.
- **포스트 합성(그레인·비네트·대비)은 톤매핑 뒤에 둡니다.** 선형 HDR 값에
  적용하면 세기가 완전히 어긋납니다. 블룸은 반대로 톤매핑 앞이어야 합니다.
- **뷰모델은 별도 씬/카메라로 렌더**하고 깊이 버퍼만 지웁니다. 벽에 파고들지 않습니다.
- **경로 탐색은 플로우 필드**입니다. 셀마다 "설 수 있는 바닥 높이"를 구워두고
  BFS 전이에서 높이 차로 통행을 판정하므로, 램프·계단은 오르고 컨테이너 위는 못 갑니다.
  개체 수와 무관하게 초당 6회 재계산이면 충분합니다.
- **드로우콜**은 아레나 4개(병합 지오메트리) + 감염체 7개(부위별 인스턴싱)
  + 이펙트 6개 수준으로 유지합니다.

### 품질 티어

`설정 → 품질`에서 수동으로 고를 수 있고, `자동`이면 하드웨어를 감지한 뒤
평균 프레임타임이 26ms를 넘으면 한 단계씩 내립니다.

| | 그림자 | 렌더 배율 | 블룸 | SMAA | 파티클 |
|---|---|---|---|---|---|
| 높음 | 2048 | 1.0 | ○ | ○ | 100% |
| 보통 | 1024 | 0.85 | ○ | ✕ | 65% |
| 낮음 | 없음 | 0.68 | ✕ | ✕ | 35% |

## 개발용 디버그 훅

콘솔에서 `window.__debug`로 접근할 수 있습니다.

```js
__debug.start()          // 게임 시작
__debug.stats()          // FPS / 드로우콜 / 삼각형 수
__debug.setWave(12)      // 특정 웨이브로 점프
__debug.spawn(2, 5)      // 중장갑체 5마리 소환 (타입 0~4)
__debug.unlockAll()      // 무기 전부 해금
__debug.god(true)        // 무적
```
