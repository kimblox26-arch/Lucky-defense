# Minecraft JS — 자바스크립트 마인크래프트 클론

외부 라이브러리 **0개**로 만든 브라우저 마인크래프트입니다.
렌더링은 WebGL2를 직접 호출하고, 텍스처·사운드·폰트까지 전부 코드로 생성합니다.
`minecraft/index.html` 을 브라우저로 열기만 하면 실행됩니다. (빌드·설치 불필요)

총 **10,600여 줄**, 23개 모듈.

---

## 인트로

`Reimagined Intro` 모드처럼 오프닝을 재구성했습니다.

1. **모장 스튜디오 오프닝** — 붉은 배경이 블록 단위로 쓸려 내려오고, 흩어져 있던 흰 픽셀이
   `MOJANG STUDIOS` 글자로 날아와 조립됩니다. 조립 순간 미세 진동과 착지 효과음이 들어갑니다.
2. **로딩** — 흙 블록 배경 위에 진행 바. 실제 청크 생성 진행률과 연동됩니다.
3. **타이틀** — 4겹 패럴랙스 파노라마(언덕·나무·구름·태양), 블록 텍스처로 채운 `MINECRAFT`
   로고, 흔들리는 노란 스플래시 문구, 메뉴 버튼.
4. **아웃트로** — 저장하고 나가면 블록 와이프 → 로고 → 감사 문구 → 엔드 카드가 재생된 뒤
   타이틀로 돌아갑니다.

인트로는 아무 곳이나 클릭하면 건너뜁니다.

## 구현된 마인크래프트 기능

### 월드
- **무한 지형** — 대륙/침식/산맥/디테일 노이즈를 합성한 높이맵, 강 침식
- **바이옴 9종** — 평원, 숲, 사막, 침엽수림, 산악, 사바나, 늪, 해변, 바다
  (기온·습도 노이즈로 결정, 바이옴별 표층·식생·나무 종류가 다름)
- **동굴** — 3D 스파게티 노이즈 2겹 교집합 터널 + 치즈 동굴(큰 공동), 깊은 곳엔 용암
- **광맥** — 석탄·철·금·레드스톤·청금석·다이아몬드·에메랄드가 고도별 분포로 생성
- **구조물** — 참나무/자작나무/가문비나무, 선인장, 사탕수수, 꽃, 버섯, 호박, 점토 퇴적
- **청크 스트리밍** — 렌더 거리에 따라 생성/메시/해제, 프레임당 시간 예산으로 분할 처리

### 조명
- **하늘광 + 블록광 2채널** (각 0~15), BFS 전파/제거 엔진
- 블록을 놓거나 부수면 해당 열의 직사광을 재계산하고 주변으로 재전파
- 횃불·용암·발광석이 실제 광원으로 동작하고, 시간대에 따라 하늘광 세기가 변함
- 메시에 **부드러운 조명**(주변 4칸 평균) + **앰비언트 오클루전** 적용

### 그래픽 (16×16 픽셀아트)
모든 텍스처는 마인크래프트 기본 리소스팩과 같은 **16×16**이며, 화면에서 뭉개지지 않도록
아래를 지켰습니다.

- 타일을 **텍스처 배열**(`TEXTURE_2D_ARRAY`)로 올려 레이어끼리 섞이지 않음 → 타일 경계 번짐 없음
- 확대 필터는 항상 `NEAREST`, 이방성 필터는 기본 꺼짐
  (이방성 필터는 확대 시에도 여러 샘플을 섞어 픽셀을 뭉개는 구현이 있음)
- 밉맵은 3단계(16→8→4)까지만 생성. 1×1까지 내려가면 먼 지형이 단색으로 뭉개짐
- 셰이더에서 음수 LOD 바이어스(-0.55)를 줘서 밉맵이 한 박자 늦게 적용됨
- 텍스처 생성 코드는 소수 좌표·선 그리기·그라디언트를 쓰지 않고 **정수 픽셀만** 찍음
- 인벤토리/핫바 아이콘은 화면에 그려질 크기(16 × GUI 배율)로 캐시해 **정수 배율 확대**만 사용
- 설정에서 **텍스처 필터**를 고를 수 있음
  - `픽셀` 밉맵 없음, 가장 또렷하지만 멀리서 반짝임
  - `선명` (기본) 밉맵 + LOD 바이어스
  - `부드럽게` 밉맵 + 이방성 필터, 먼 지형이 가장 잡티 없음

### 렌더링
- WebGL2 `TEXTURE_2D_ARRAY` 기반 청크 배칭, 면 컬링, 절두체 컬링
- 하늘 그라디언트 셰이더(시야 벡터 기반), 태양·달·별 900개·노을
- 블록 단위 구름층(스크롤), 거리 안개, 수중 필터
- 물 반투명 패스(카메라 거리순 정렬), 십자형 식물, 크랙 오버레이 10단계
- 1인칭 손/아이템, 시점 흔들림, 달리기 시 FOV 증가

### 플레이
- **이동** — 걷기/달리기/웅크리기(모서리 보호)/점프/수영/사다리/크리에이티브 비행
- **채굴** — 블록 경도 × 도구 종류 × 도구 등급으로 채굴 시간 계산, 잘못된 도구면 드롭 없음
- **제작** — 인벤토리 2×2, 제작대 3×3. 정형/비정형 조합 **80여 종**
  (도구 25종, 방어구 16종, 건축 자재, 음식, 활·화살, TNT…)
- **제련** — 화로에 연료·재료를 넣으면 시간이 흐르며 제련, 불꽃/화살표 진행 표시, 경험치 회수
- **보관** — 상자 27칸 (블록 엔티티로 위치별 저장)
- **농사** — 괭이로 경작지 만들기 → 씨앗 심기 → 4단계 성장 → 밀 수확 → 빵 제작
  (물 근처면 젖은 땅이 되어 빠르게 자람)
- **생존** — 체력 20, 허기·포만감·탈진 시스템, 자연 회복, 굶주림·낙하·용암·선인장·익사 피해
- **방어구** — 4부위, 재질별 방어력과 내구도, 피해 감쇠
- **경험치** — 광물·몹·제련에서 획득, 레벨업 연출

### 몹
| 적대 | 우호 |
|---|---|
| 좀비(추격·근접), 스켈레톤(거리 유지·활), 크리퍼(접근·점화·폭발), 거미(빠름) | 돼지, 소, 양, 닭 |

- 밝기·시간대·거리 기반 스폰, 멀어지면 디스폰
- 장애물 자동 점프, 수영, 낙하 피해, 좀비·스켈레톤은 낮에 불탐
- 피격 시 넉백·붉은 점멸, 사망 시 아이템과 경험치 드롭

### 물리 / 시뮬레이션
- AABB 축별 스윕 충돌 + 자동 계단 오르기
- 유체 확산(레벨 0~7, 소스/흐름 구분), 물+용암 → 돌/흑요석
- 모래·자갈 낙하(낙하 블록 엔티티)
- 랜덤 틱: 잔디 번식/소멸, 작물 성장, 묘목 → 나무, 잎 삭기, 얼음 해동, 선인장·사탕수수 성장
- TNT 점화 → 폭발(블록 파괴 저항 계산, 연쇄 폭발, 범위 피해)

### 그 외
- **F3 디버그 화면** — 좌표·청크·바이옴·밝기·드로우콜·삼각형·엔티티·시드
- **채팅/명령어** — `/gamemode` `/time` `/tp` `/give` `/summon` `/kill` `/clear` `/seed` `/save` `/heal` `/speed`
- **저장** — localStorage에 "생성 결과 대비 변경분"만 저장하므로 용량이 작음. 60초 자동 저장
- **사운드** — WebAudio로 합성한 재질별 채굴·발소리·피격·폭발·몹 소리 + 잔잔한 배경 화음
- **절차적 텍스처** — 212개 타일(블록·아이템·도구·방어구·몹·크랙)을 전부 캔버스로 그림
- 마우스 포인터 락, 터치 시점 조작, 설정(렌더 거리·FOV·감도·음량) 저장

## 조작법

| 키 | 동작 |
|---|---|
| `W` `A` `S` `D` | 이동 |
| `Space` | 점프 / 수영 (크리에이티브에서 두 번 누르면 비행) |
| `Shift` | 웅크리기 |
| `Ctrl` | 달리기 |
| 마우스 왼쪽 | 채굴 / 공격 (누르고 있기) |
| 마우스 오른쪽 | 설치 / 사용 / 먹기 / 활 당기기 |
| 마우스 가운데 | 블록 복사 |
| `1`~`9`, 휠 | 핫바 선택 |
| `Q` / `Shift+Q` | 1개 / 전부 버리기 |
| `E` | 인벤토리 |
| `T` / `/` | 채팅 / 명령어 |
| `F3` | 디버그 정보 |
| `F1` | UI 숨기기 |
| `Esc` | 일시정지 |
| `R` | 리스폰 |

인벤토리에서는 좌클릭(집기/놓기), 우클릭(절반 집기/1개 놓기), `Shift`+클릭(빠른 이동)이 됩니다.

## 파일 구조

```
minecraft/
├── index.html          화면 구성 · DOM 패널 · 스크립트 로드 순서
├── css/game.css        레이아웃, 일시정지/설정/조작법 패널
└── js/
    ├── util.js         수학 · 난수 · AABB · 4x4 행렬 · 절두체
    ├── noise.js        펄린 2D/3D · fBm · 리지드 · 보로노이
    ├── pixelfont.js    5x7 비트맵 폰트 (인트로 로고용)
    ├── textures.js     212개 타일 절차적 생성
    ├── blocks.js       블록 81종 레지스트리
    ├── items.js        아이템 · 도구 · 방어구 · 조합법 · 제련
    ├── chunk.js        16×128×16 청크 저장소
    ├── worldgen.js     지형 · 바이옴 · 동굴 · 광맥 · 장식
    ├── world.js        청크 관리 · 조명 엔진 · 유체 · 틱 · 레이캐스트
    ├── mesher.js       면 컬링 + AO + 부드러운 조명 메시 빌더
    ├── renderer.js     WebGL2 렌더러 (지형/하늘/구름/엔티티/손)
    ├── particles.js    파괴 조각 · 물보라 · 연기 · 불꽃
    ├── audio.js        WebAudio 절차적 효과음 · 배경 음악
    ├── inventory.js    컨테이너 · 제작 그리드 · 슬롯 조작
    ├── entity.js       엔티티 물리 · 몹 AI · 아이템 · 화살 · TNT
    ├── player.js       플레이어 (이동/채굴/설치/전투/생존)
    ├── gui.js          인벤토리 · 제작대 · 화로 · 상자 · 크리에이티브
    ├── hud.js          체력/허기/핫바/디버그/채팅/사망 화면
    ├── intro.js        모장 인트로 · 타이틀 · 아웃트로
    ├── save.js         localStorage 저장/불러오기
    └── main.js         입력 · 게임 루프 · 명령어
```

## 실행

```
minecraft/index.html 을 브라우저에서 열기
```

WebGL2를 지원하는 최신 브라우저(Chrome, Edge, Firefox, Safari 15+)가 필요합니다.
로컬 파일(`file://`)에서도 그대로 동작합니다. 모듈·페치·외부 리소스를 쓰지 않기 때문입니다.
