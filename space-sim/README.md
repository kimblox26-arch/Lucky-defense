# 🔮 Marble Cosmos — 구슬 우주 시뮬레이터

구슬(marble)로 이루어진 천체들이 실제 물리 법칙에 따라 움직이는 **3D 스페이스 심 / 유니버스 샌드박스**입니다.
설치 없이 `index.html` 을 열기만 하면 **PC · 노트북 · 태블릿 · 스마트폰** 어디서나 실행됩니다.

---

## ▶ 실행 방법

1. 압축을 풀고 `index.html` 을 더블클릭 (크롬 · 엣지 · 사파리 · 파이어폭스)
2. 모바일에서는 폴더를 그대로 두고 `index.html` 을 브라우저로 열면 됩니다.
3. 인터넷 연결이 없어도 동작합니다. (three.js·실사 텍스처를 모두 로컬에 포함)

---

## 🎮 메인 화면

- **플레이** — 시뮬레이션 시작 (기본 시나리오: 태양계)
- **설정** — 그래픽 / 물리 옵션
- **언어** — 한국어 · English · 日本語
- **나가기** — 종료

## 🌌 주요 기능

### 물리
| 기능 | 설명 |
|---|---|
| N-체 중력 | 모든 천체가 서로 만유인력을 주고받음 (속도 베를레 적분 + 적응형 서브스텝) |
| **로슈 한계** | 유체 한계 `2.44 R(ρM/ρm)^⅓` · 강체 한계 `1.26 R(ρM/ρm)^⅓` 를 실시간 계산.<br>한계 안으로 들어온 위성은 **조석력으로 산산조각** 나며, 조각들이 **진행 경로를 따라 호(arc)를 이루고** 퍼져 고리가 됨 |
| 조석 가열 | 로슈 한계 근처의 천체는 내부가 가열되어 붉게 달아오름 |
| 충돌 | 합체 / 튕김 / 파쇄 / 현실적(충돌 속도와 탈출 속도를 비교해 자동 판정) |
| **파편 → 위성 형성** | 충돌 시 분출된 파편이 원반을 이루고, 서로 저속으로 부딪히며 **강착(accretion)** 하여 일정 질량을 넘으면 새 위성으로 승격 |
| 블랙홀 | 사건의 지평선(슈바르츠실트 반지름) 안으로 들어온 천체를 흡수하며 질량 증가 |
| 항성 복사 | 광도에 따른 평형 온도 계산, 거주가능영역 표시 |
| 궤도 요소 | 긴반지름 · 이심률 · 주기 · 원점 · 근점 실시간 계산 |
| 시간 제어 | 일시정지 · 12단계 배속(1초/초 ~ 1000년/초) · **역재생** |

### 천체 카탈로그 (150+ 종)
항성 · 행성 · 위성 · 왜소행성 · 소행성 · 혜성 · 운석 · 외계행성 · 블랙홀 · 중성자별 · 백색왜성 · 갈색왜성 · 사용자 정의
(태양계 전체, 프록시마/시리우스/베텔게우스/UY 방패자리, TRAPPIST-1 전 행성, 궁수자리 A\*, M87\*, TON 618,
핼리 혜성, 오무아무아, 베누, 류구, 아포피스 … 실제 관측값 기반 질량·반지름·온도)

### 표면 — **실제 탐사선이 촬영한 사진**
모든 천체 표면은 NASA / JPL / USGS / ESA 가 공개한 **실측 관측 자료**를 정사영으로 펼친
실사 텍스처입니다. (절차적 그림이 아닙니다 — 출처 목록은 `tex/CREDITS.md`)

| 천체 | 원본 관측 |
|---|---|
| 지구 | NASA **Blue Marble**(MODIS) + **야간 도시 불빛**(VIIRS) + 구름 + 해양 반사 + 지형 범프 |
| 달 | **Lunar Reconnaissance Orbiter / Clementine** (+범프) |
| 수성 | **MESSENGER** 전구 모자이크 |
| 금성 | **Magellan** 레이더 표면 지도 |
| 화성 | **Viking / MGS MOLA** (+범프) |
| 목성·토성 | **Cassini / Voyager** (대적점, 카시니 간극 포함 실제 고리 텍스처) |
| 천왕성·해왕성 | **Voyager 2** |
| 명왕성·카론 | **New Horizons** (2015, 톰보 영역 '하트') |
| 갈릴레이 위성 | **Galileo / Voyager** (이오의 화산, 유로파의 균열) |
| 토성 위성 | **Cassini-Huygens** (타이탄·엔셀라두스·이아페투스 명암 반구 …) |
| 천왕성·해왕성 위성 | **Voyager 2** (미란다·트리톤 …) |
| 세레스·베스타 | **Dawn** |
| 베누·에로스·이다·가스프라 | **OSIRIS-REx / NEAR / Galileo** |
| 태양 | 광구(백색광) 관측 이미지 + **주연감광(limb darkening)** 물리 셰이더 |
| 배경 | 실제 **은하수 전천 파노라마** |

- 항성은 태양 광구 이미지에 **흑체 복사 색(온도 → RGB)** 을 입혀 표현합니다.
- 사진이 존재하지 않는 외계행성·가상 천체는 **가장 닮은 실제 천체의 사진**으로 대체하고 색조를 보정합니다.
- 블랙홀은 사진 대신 **사건의 지평선 + 광자 고리 + 강착 원반** 을 물리적으로 렌더링합니다.
- 렌더링은 선형 색 공간(sRGB) + **ACES 필름 톤매핑** 을 사용합니다.

### 구슬(Marble) 모드
모든 천체에 유리 구슬 셸 + 은하수 반사 + 광택 하이라이트가 적용되어, 우주가 **구슬 상자**처럼 보입니다.
`구슬 뿌리기` 툴로 원하는 곳에 구슬을 흩뿌릴 수 있고, `구슬 상자` 시나리오는 구슬 성단을 만들어 줍니다.

### 시나리오
태양계 · 지구-달 · 목성계 · 토성계 · 쌍성계 · 블랙홀 강착 원반 · **로슈 한계 실험** ·
**충돌 → 위성 형성(테이아 충돌)** · TRAPPIST-1 · 카오스 은하 · 구슬 상자 · 무작위 계 · 빈 우주

## 🕹 조작법

| 조작 | PC | 모바일 |
|---|---|---|
| 회전 | 드래그 | 한 손가락 드래그 |
| 확대/축소 | 마우스 휠 | 두 손가락 핀치 |
| 이동(팬) | 우클릭 드래그 / Shift+드래그 | 두 손가락 드래그 |
| 선택 | 클릭 | 탭 |
| 추적 | 더블클릭 | 더블탭 |

**툴** ①선택 ②배치 ③발사 ④구슬 뿌리기 ⑤측정
**단축키** `Space` 일시정지 · `←/→` 배속 · `T` 궤적 · `R` 로슈 한계 · `G` 중력장 · `L` 이름표 ·
`M` 구슬 모드 · `V` 속도 벡터 · `H` 거주가능영역 · `F` 추적 · `Q` 소환 · `P` 시나리오 · `Del` 삭제 · `Esc` 메뉴
