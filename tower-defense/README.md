# INFINITE TOWER DEFENSE v2 (무한의 탑 디펜스)

의존성 0 · 빌드 0 · 에셋 0 의 순수 HTML5 Canvas + JavaScript 게임.
`tower-defense/index.html` 을 브라우저로 열면 바로 실행된다.
(구글 로그인만 웹 서버 접속이 필요하다 — 아래 참고)

전체 코드 **10,000줄+** / 유닛 **108종** / 적 **103종(보스 20 · 정예 12)**

---

## 1. 계정 · 프로필

| 기능 | 설명 |
|---|---|
| 회원가입 / 로그인 | 아이디·비밀번호·닉네임. 비밀번호는 **SHA-256 + 랜덤 솔트** 해시로만 저장 (원문 미저장) |
| Google 계정 로그인 | Google Identity Services 연동. `js/config.js` 에 클라이언트 ID를 넣으면 활성화 |
| 게스트 시작 | 로그인 없이 바로 플레이 (이 브라우저에만 저장) |
| 계정별 세이브 | 젬·업적·도감·명예강화·전적이 계정에 귀속 |
| 프로필 꾸미기 | 몸 9 · 머리 7 · 헤어 8 · 장비 12 · 무기 16 · 날개 5 · 피부색 10 · 머리색 13 · 테마색 12 |
| 칭호 12 / 프레임 9 / 배지 9 | 조건 달성·젬 구매로 해금, 로비·결과 화면에 반영 |
| 레벨 · 경험치 | 전투 결과(웨이브·처치·보스·승리)로 획득 |
| 출석 보상 · 일일 퀘스트 | 7일 연속 보상, 매일 3개 퀘스트 |

> ⚠️ 서버가 없는 정적 게임이므로 계정은 **브라우저(localStorage) 로컬 계정**이다.
> 다른 기기와 동기화되지 않는다. 구글 로그인도 신원 확인용이며 클라우드 세이브는 없다.

### Google 로그인 켜는 법
1. [Google Cloud Console](https://console.cloud.google.com) → OAuth 클라이언트 ID(웹) 생성
2. **승인된 자바스크립트 원본**에 배포 주소 등록 (`https://<user>.github.io`, `http://localhost:8080` 등)
3. `js/config.js` 의 `GOOGLE_CLIENT_ID` 에 발급받은 ID 입력
4. `file://` 이 아닌 웹 서버로 접속 (`npx http-server` 등)

## 4. 그래픽 엔진 (`js/gfx.js`)

- **레이어드 캐릭터 리그**: 그림자 → 다리(5종) → 망토 → 몸통(12종) → 팔(조준 방향 IK) → 머리(8종) → 헤어(8종) → 헤드기어(12종) → 무기(24종) → 날개(4종) → 등급 오라(4종)
- 색 램프(하이라이트/기본/음영/외곽 5단계) · 금속 그라디언트 · 천 주름 · 림라이트 · 눈 깜빡임 · 걷기 사이클 · 공격 반동
- **스프라이트 캐시**: 적은 (종류×크기×프레임 8) 오프스크린 캔버스로 캐싱, 상태이상 틴트도 캐싱 → 적 300기에서도 가볍다
- **지형 렌더러**: 32비트 해시 기반 FBM 노이즈 텍스처, 타일별 결정론적 장식물(풀·나무·바위·꽃·뼈·해골·얼음·용암균열·버섯·폐허·공허균열·모래언덕·수정), 자갈 깔린 도로, 시작/도착 결계
- **환경**: 날씨 5종(비·눈·불티·모래폭풍·잿가루), 맵별 환경광(soft-light), 상단 광원
- **전투 연출(`js/effects.js`)**: 원소 14종별 전용 타격 이펙트, 충격파 링, 지면 데칼, 스피드라인, 치명타/처형/보호막파괴/보스등장/웨이브클리어/승급 연출

## 5. 편의 기능

- **자동 최적 배치(A)** — 경로 노출 점수를 계산해 사거리 짧은 유닛을 좋은 자리로
- **유닛 잠금(L)** — 합성·판매·일괄정리에서 보호
- **일괄 정리** — 일반/희귀 미만 1성 유닛 한 번에 판매
- **유닛 기여도 순위** — 누적 피해·처치 막대 그래프
- **웨이브 예고** — 다음 웨이브 구성 미리보기
- **튜토리얼** — 최초 플레이 시 6단계 안내 (조건 달성 시 자동 진행)

## 6. 조작

- 탭/클릭 : 유닛 선택 · 드래그 : 이동, 같은 유닛 위에 놓으면 합성
- **Q** 소환 · **W** 자동합성 · **E** 웨이브 · **R** 배속 · **A** 자동배치 · **L** 잠금 · **Space** 일시정지 · **1~9** 스킬
- 세로 화면에서는 맵이 자동으로 90° 전치되어 화면을 꽉 채운다.

## 7. 파일 구조

```
tower-defense/
├── index.html          UI 마크업
├── css/style.css       전체 스타일 (반응형 / 모바일 레이아웃)
└── js/
    ├── config.js       Google 클라이언트 ID 등 설정
    ├── util.js         수학·난수·파티클·화면효과·WebAudio 합성 사운드·저장
    ├── data.js         유닛/적/보스/맵/모디파이어/스킬/연구/시너지/업적/아바타/상점/퀘스트
    ├── gfx.js          고급 그래픽 엔진 (캐릭터 리그·스프라이트 캐시·지형·날씨)
    ├── effects.js      전투 연출 라이브러리
    ├── render.js       유닛/적/투사체/맵/초상화 드로잉
    ├── entities.js     적·유닛·투사체·소환수·장판 + 피해 계산 파이프라인
    ├── game.js         코어 루프·웨이브·경제·소환/합성·스킬·시너지·저장
    ├── account.js      계정/인증/프로필/출석/퀘스트
    ├── lobby.js        로그인 화면 + 메인 로비 + 모든 패널
    ├── tutorial.js     최초 플레이 안내
    └── ui.js           인게임 HUD·유닛패널·모달·결과 화면
```

효과음과 배경음은 외부 파일 없이 WebAudio로 실시간 합성한다.
