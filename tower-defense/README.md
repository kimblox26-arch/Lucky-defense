# INFINITE TOWER DEFENSE (무한의 탑 디펜스)

의존성 없는 순수 HTML5 Canvas + JavaScript 타워 디펜스.
`tower-defense/index.html` 을 브라우저로 열면 바로 실행된다. (빌드/서버 불필요)

## 핵심 시스템

| 시스템 | 내용 |
|---|---|
| 유닛 | 46종 · 7등급(일반→초월) · 8클래스 · 10원소 · 3성급 · 골드 강화 레벨 |
| 적 | 37종 일반 + 10종 보스 · 분열/재생/보호막/치유/소환/순간이동/격노/비행/유령 |
| 소환 | 골드로 랜덤 소환(가챠). 행운 수치가 고등급 확률을 올린다 |
| 합성 | 동일 유닛 3기 → 성급 상승, 3성 3기 → **상위 등급 승급** |
| 시너지 | 클래스 8종 · 원소 10종, 보유 수에 따라 3단계 보너스 |
| 상태이상 | 화상 · 둔화 · 빙결 · 독중첩 · 감전/기절 · 저주 · 속박 · 방어파쇄 |
| 스킬 | 8종 액티브(메테오/빙결/뇌우/골드러시/오버드라이브/섬멸/시간왜곡/성역) |
| 연구 | 16종 인게임 강화(공격력·속도·사거리·치명타·골드·행운·이자·진지확장 등) |
| 명예 강화 | 업적으로 얻은 💎로 사는 영구 강화 5종 |
| 업적 | 24종, 달성 시 젬 보상 |
| 맵 | 5개 전장(난이도 x1.0 ~ x2.4), 100웨이브 클리어 시 다음 맵 해금 |
| 무한 회귀 | 100웨이브 이후 회차가 올라가며 난이도 재상승 |

## 조작

- **탭/클릭** : 유닛 선택 (상세 패널)
- **드래그** : 유닛 이동, 같은 유닛 위로 놓으면 합성
- **Q** 소환 · **W** 자동합성 · **E** 웨이브 시작 · **R** 배속 · **Space** 일시정지 · **1~8** 스킬
- 세로 화면에서는 맵이 자동으로 90° 전치되어 화면을 꽉 채운다.

## 파일 구조

```
tower-defense/
├── index.html        UI 마크업
├── css/style.css     전체 스타일 (반응형 / 모바일 레이아웃)
└── js/
    ├── util.js       수학·난수·파티클·화면효과·WebAudio 합성 사운드·저장
    ├── data.js       유닛/적/보스/맵/스킬/연구/시너지/업적 데이터
    ├── render.js     절차적 스프라이트(몸통·머리·무기 조합) 및 맵/투사체 렌더
    ├── entities.js   적·유닛·투사체·소환수·장판 + 피해 계산 파이프라인
    ├── game.js       코어 루프·웨이브·경제·소환/합성·스킬·시너지·저장
    └── ui.js         HUD·스킬바·유닛패널·연구/도감/업적/설정 모달
```

효과음과 배경음은 외부 파일 없이 WebAudio로 실시간 합성한다.
진행도(젬·업적·명예 강화·설정)는 localStorage에 저장된다.
